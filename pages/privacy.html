Политика конфиденциальности

Настоящая Политика конфиденциальности персональных данных действует в отношении всей информации, которую сайт ПрофЭлектрик Казань, расположенный на доменном имени https://www.profielectric.ru/, может получить о Пользователе во время использования сайта, его сервисов, форм и услуг.

1. Общие положения

1.1. Использование сайта Пользователем означает согласие с настоящей Политикой конфиденциальности и условиями обработки его персональных данных.

1.2. В случае несогласия с условиями Политики конфиденциальности Пользователь должен прекратить использование сайта.

1.3. Настоящая Политика применяется только к сайту https://www.profielectric.ru/.

2. Предмет политики конфиденциальности

2.1. Настоящая Политика устанавливает обязательства Администрации сайта по неразглашению и обеспечению режима защиты персональных данных, которые Пользователь предоставляет при заполнении форм на сайте.

2.2. Персональные данные включают:

  • имя Пользователя (если указано);
  • номер телефона;
  • текст обращения или описания проблемы;
  • технические данные (IP-адрес, cookies, данные браузера).

3. Цели сбора персональных данных

Персональные данные Пользователя используются для:

  • обработки заявок и обращений;
  • обратной связи с Пользователем;
  • оказания услуг электрика;
  • улучшения качества работы сайта.

4. Обработка и хранение данных

4.1. Обработка персональных данных осуществляется без ограничения срока.

4.2. Персональные данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

4.3. Данные могут передаваться в сторонние сервисы (например, Telegram или сервисы обработки форм) исключительно для обработки заявок Пользователя.

5. Обязанности сторон

Пользователь обязан:

  • предоставлять достоверные данные.

Администрация сайта обязана:

  • использовать данные только в рамках данной Политики;
  • обеспечивать защиту персональных данных.

6. Заключительные положения

6.1. Администрация сайта вправе вносить изменения в Политику без согласия Пользователя.

6.2. Новая редакция Политики вступает в силу с момента её размещения на сайте.

6.3. Актуальная версия Политики всегда доступна по адресу: https://www.profielectric.ru/pages/privacy
